# 复合变量类型（Compound Variable Type）功能说明

## 概述

复合变量类型是一种新的变量声明方式，允许将多个字段打包成一个整体变量。这种类型在声明时不会立即push到栈上，只有在承接其它栈上变量后，才能在首次访问字段时进行拆分。

## 语法

### 1. 基本语法

使用大括号 `{}` 声明复合类型变量：

```
变量名: {字段1:类型1, 字段2:类型2, ...}
```

### 2. 支持的字段类型

复合类型中的字段**只支持**以下两种类型：

- **hex<N>**：N字节的十六进制数据
  - 例如：`hex20`（20字节）、`hex32`（32字节）
  
- **uint64[N]**：N个uint64元素的数组
  - 例如：`uint64[3]`（3个uint64，共24字节）

### 3. 使用场景

#### 场景1：函数体内声明

```python
def myFunction():
    # 声明复合类型变量
    list: {a:hex20, b:hex32, c:hex32}
    
    # 从栈上承接数据
    temp: hex = "0x54..."  # 包含长度前缀的完整数据
    list = temp
    
    # 访问字段（触发拆分）
    field_a: hex = list.a
    field_b: hex = list.b
```

#### 场景2：结构体字段

```python
Struct MyStruct:
    data: {a:hex20, b:hex32, c:hex32}
    value: uint64

def processStruct(s: MyStruct):
    # 访问复合类型字段的子字段
    val_a: hex = s.data.a
    val_b: hex = s.data.b
```

## 数据格式

### 长度前缀

复合类型数据的最前面包含长度前缀，用于表示总数据长度：

- **总字节数 ≤ 255**：使用1字节表示长度
- **总字节数 ≤ 65535**：使用2字节表示长度
- **总字节数 > 65535**：使用4字节表示长度

### 数据布局

```
[长度前缀][字段1数据][字段2数据][字段3数据]...
```

**示例**：`{a:hex20, b:hex32, c:hex32}`

- 总字节数：20 + 32 + 32 = 84字节
- 长度前缀：1字节（84 < 255）
- 完整数据：`[0x54][20字节a数据][32字节b数据][32字节c数据]`

## 拆分机制

### 拆分时机

复合类型变量在**首次访问任一字段**时触发拆分。拆分后，各字段作为独立的栈元素存在。

### 拆分过程

1. **Roll到栈顶**：将复合类型变量roll到栈顶
2. **去除长度前缀**：使用 `OP_SPLIT` + `OP_NIP` 操作（等价于 `slice(lengthPrefixBytes, -1)`）
3. **逐个分割字段**：对每个字段（除最后一个）使用 `OP_SPLIT` + `OP_SWAP`
4. **注册字段**：将各字段注册到符号表

### 栈顺序

拆分后，字段在栈上的顺序为：

```
栈底 [字段0] [字段1] [字段2] ... [字段N] 栈顶
```

即：**第一个字段在栈底，最后一个字段在栈顶**

**示例**：`{a:hex20, b:hex32, c:hex32}` 拆分后：

```
栈底 [a] [b] [c] 栈顶
```

## 实现细节

### 1. Parser层

- 在 `parseStructFieldType()` 和 `parseStatement()` 中解析大括号语法
- 创建 `CompoundFieldInfo` 列表
- 设置 `VarDeclNode.isCompoundType = true`

### 2. 符号表管理

- `defineCompoundType()`：注册复合类型信息
- `isCompoundTypeSymbol()`：检查是否为复合类型
- `getCompoundTypeInfo()`：获取复合类型详细信息
- `isCompoundTypeSplitted()` / `markCompoundTypeSplitted()`：跟踪拆分状态

### 3. 字节码生成

#### 变量声明（VarDeclNode）

```cpp
if (node.isCompoundType) {
    // 计算总字节数和长度前缀字节数
    // 创建 CompoundTypeInfo
    // 调用 defineCompoundType 注册
    // 使用零成本重命名承接数据（不push到栈）
}
```

#### 字段访问（FieldAccessNode）

```cpp
if (isCompoundTypeSymbol(baseElement)) {
    if (!isCompoundTypeSplitted(baseElement)) {
        // 首次访问，执行拆分
        // 1. Roll到栈顶
        // 2. OP_SPLIT + OP_NIP 去除长度前缀
        // 3. 逐个 OP_SPLIT + OP_SWAP 分割字段
        // 4. 注册各字段到符号表
        // 5. 标记已拆分
    }
    // 获取字段位置并访问
}
```

#### 结构体参数展开（expandStructParameter）

```cpp
if (fieldType == "__compound__") {
    // 从结构体定义获取复合类型字段信息
    // 创建 CompoundTypeInfo
    // 调用 defineCompoundType 注册
    // Push到栈上（emitUnlock）
}
```

## 字节码操作码

| 操作 | 操作码   | 说明                     |
| ---- | -------- | ------------------------ |
| 分割 | OP_SPLIT | 在指定位置分割字节数组   |
| 交换 | OP_SWAP  | 交换栈顶两个元素         |
| 移除 | OP_NIP   | 移除栈顶下方的元素       |
| Roll | OP_ROLL  | 将指定位置的元素移到栈顶 |

## 示例代码

### 完整示例

```python
Contract CompoundExample:
    Struct Transaction:
        hashes: {txid: hex32, blockhash: hex32}
        data: {timestamp: uint64[1], amount: uint64[1]}

    def processTransaction(tx: Transaction):
        # 访问第一层字段
        tx_id: hex = tx.hashes.txid
        block_hash: hex = tx.hashes.blockhash
        
        # 访问另一个复合类型字段
        time_data: uint64 = tx.data.timestamp
        amount_data: uint64 = tx.data.amount
        
        return

    def createData():
        # 函数内创建复合类型变量
        info: {id: hex32, flags: uint64[2]}
        
        # 承接数据（包含长度前缀）
        # 总长度：32 + 16 = 48字节
        # 长度前缀：0x30 (48的十六进制)
        raw_data: hex = "0x30abcdef0123456789abcdef0123456789abcdef0123456789abcdef01234567010000000000000002000000000000"
        info = raw_data
        
        # 使用字段
        identifier: hex = info.id
        flag_array: uint64 = info.flags
        
        return
```

## 注意事项

1. **类型限制**：复合类型中只能使用 `hex<N>` 和 `uint64[N]` 两种类型
2. **声明不入栈**：复合类型变量在声明时不会push到栈上
3. **必须承接**：必须先承接其它栈上变量，才能访问字段
4. **一次拆分**：首次访问任一字段时进行拆分，后续访问直接使用拆分后的字段
5. **长度前缀**：数据必须包含正确的长度前缀
6. **结构体字段**：作为结构体字段时，在函数参数初始化时会作为整体push到栈上
