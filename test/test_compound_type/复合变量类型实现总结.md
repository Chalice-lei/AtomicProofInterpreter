# 复合变量类型实现总结

## 修改日期
2025-12-12

## 功能概述

实现了复合变量类型功能，支持使用大括号语法声明包含多个字段的整体变量。这些变量在声明时不会push到栈上，只有在承接其它栈上变量并访问字段时才会进行拆分。

## 主要特性

1. **大括号语法**：`变量名: {字段1:类型1, 字段2:类型2, ...}`
2. **支持的类型**：`hex<N>` 和 `uint64[N]`
3. **延迟入栈**：声明时不push，承接数据后才能访问
4. **自动拆分**：首次访问字段时自动拆分
5. **长度前缀**：数据包含长度前缀（1、2或4字节）
6. **结构体支持**：可作为结构体字段使用
7. **函数参数支持**：作为结构体字段在函数参数中自动初始化

### 2. 修改内容

#### 2.1 expandStructParameter 函数（行3800-3811）

**修改前的问题**：
- 复合类型字段作为结构体字段在函数参数中时，只定义符号并push到栈，但没有注册复合类型信息
- 导致访问子字段时（如 `s.data.a`），`isCompoundTypeSymbol()` 返回false，无法正确拆分

**修改后的解决方案**：
- 从结构体定义中获取复合类型字段的完整信息（compoundFields列表）
- 计算总字节数和长度前缀字节数
- 创建 `CompoundTypeInfo` 并调用 `defineCompoundType()` 注册
- 然后再定义符号并push到栈上

## 拆分机制详解

### 栈操作序列

对于复合类型 `{a:hex20, b:hex32, c:hex32}`：

```
初始状态：[...其它数据] [list(含长度前缀的完整数据)] [...]

1. Roll到栈顶
   [...其它数据] [list]

2. OP_SPLIT(1) + OP_NIP  // 去除1字节长度前缀
   [...其它数据] [去除长度后的数据]

3. OP_SPLIT(20) + OP_SWAP  // 分割a
   [...其它数据] [b和c的数据] [a]

4. OP_SPLIT(32) + OP_SWAP  // 分割b
   [...其它数据] [c的数据] [a] [b]

5. 最终状态（无需再split，剩余就是c）
   [...其它数据] [a] [b] [c]
```

**栈顺序确认**：a在栈底，c在栈顶 ✅

### 字节码对应关系

| 需求操作     | Bitcoin Script 操作码 |
| ------------ | --------------------- |
| slice(1, -1) | OP_SPLIT + OP_NIP     |
| split字段    | OP_SPLIT + OP_SWAP    |
| roll到栈顶   | OP_ROLL               |

## 使用示例

### 示例1：基本用法

```python
def example1():
    # 声明复合类型变量
    data: {id: hex32, value: hex32}
    
    # 承接栈上数据
    temp: hex = "0x40..."  # 64字节 + 1字节长度前缀
    data = temp
    
    # 访问字段（触发拆分）
    id_val: hex = data.id
    val: hex = data.value
    
    return
```

```python
def processRecord(r: Record):

    return
```

## 技术要点

### 1. 零成本重命名

复合类型变量在承接数据时，使用零成本重命名（`m_scopePtr->rename()`），不生成额外的字节码，只是更改符号表中的名称。

### 2. 延迟拆分

只有在首次访问字段时才进行拆分，避免不必要的栈操作。拆分后通过 `markCompoundTypeSplitted()` 标记，后续访问直接使用已拆分的字段。

### 3. 长度前缀计算

```cpp
size_t lengthPrefixBytes = 0;
if (totalBytes <= 255) {
    lengthPrefixBytes = 1;
} else if (totalBytes <= 65535) {
    lengthPrefixBytes = 2;
} else {
    lengthPrefixBytes = 4;
}
```

### 4. 结构体字段特殊处理

结构体字段的复合类型需要设置 `isStructField = true`，以便在函数参数初始化时能够正确处理。

## 限制和约束

1. **类型限制**：复合类型字段只能是 `hex<N>` 或 `uint64[N]`
2. **必须承接**：声明后必须承接栈上数据才能使用
3. **长度前缀必须正确**：数据必须包含正确的长度前缀
4. **一次拆分**：拆分后无法还原为整体
